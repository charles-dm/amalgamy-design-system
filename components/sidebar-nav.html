Click any item to set it active. Click the toggle in the topbar (or press ⌘B) to collapse the sidebar. Hover an item while collapsed to see the CSS-only tooltip.

Active item — exact treatment background: var(--color-accent-muted-bg) · #082223
box-shadow: inset -2px 0 0 0 var(--color-accent) — right indicator, not border-right
icon + label color: var(--color-accent) · #2ECEC0
Collapse transition width-only · 220ms cubic-bezier(0.4, 0, 0.2, 1)
label reveal: opacity + translateX(-6px → 0) · 160ms delay 30ms
never animate height, top, left, or transform: scaleX
Logo box border uses --color-accent-hover (#45D9CD), not --color-accent (#2ECEC0).
Intentional — the logo box is high-emphasis and uses the brighter token.
Spacer rule flex: 1 0 0; min-height: 1px; — not flex: 1 alone.
The explicit flex-shrink: 0 prevents collapse when the nav content is tall (which would push the bottom items up into the primary section).
Collapsed tooltip CSS-only. Each item carries data-label="...".
.sidebar-item::after { content: attr(data-label) } in the collapsed state. No JavaScript.
